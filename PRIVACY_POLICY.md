# Privacy Policy for Pdf Image Toolkit: offline

**Last updated:** November 2026

**Pdf Image Toolkit: offline** ("the Application") is developed by **MrKalita**. Your privacy is critically important to us.

---

### 1. Zero Data Collection & Offline Execution
Pdf Image Toolkit: offline operates 100% offline:
- All document parsing, merging, splitting, compression, and image conversions take place exclusively in local memory (RAM) and private temporary directories on your Windows device.
- Files never leave your computer. No document content, page structures, images, or extracted text are ever logged, stored, or transmitted to any external server.
- The Application makes zero external network calls and contains zero analytics SDKs, advertising trackers, or telemetry beacons.

### 2. Local File System & Overwrite Protection
- The Application only accesses files explicitly chosen by you through standard Windows file picker dialogs or drag-and-drop actions.
- The Application never overwrites your original files; all outputs are saved with non-destructive suffixes (e.g. `document_compressed.pdf`).
- Temporary processing files are automatically wiped upon operation completion and application exit.

### 3. In-App Purchases
The Application offers an optional lifetime license upgrade ("Pro"). All billing, transactions, and licensing validations are handled exclusively by Microsoft Corporation via the official Microsoft Store client. No financial data or payment details are collected or accessible by the Application.

### 4. Contact
For questions, support, or inquiries regarding this Privacy Policy, please open an issue on the project's GitHub repository or contact the developer via the Microsoft Store.
